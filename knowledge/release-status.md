## Retired library fork

Matt's Library: Updated is deprecated in favor of [original Matt's Library 0.7.0](https://mods.factorio.com/mod/matts-lib). Matt's Logistics uses the original dependency. The [fork repository](https://github.com/FactorioMods/matts-lib-updated) is archived, retaining its commit history and final 1.0.1 release. Older release archives are retained in verified private backups.

## Public release cleanup

The explicitly approved 2026-11-05 cleanup removed 42 old Mod Portal releases, 45 old GitHub releases and 94 noncurrent tag refs from our fork repositories. Each of the 14 forks, including the retired library, retains its current stable GitHub release/tag. The removed refs include old original-version tags copied into our forks; original upstream repositories and commit histories were preserved. Verified private bundles, release notes and asset backups retain the removed versions. Release versions in the table above did not change.

Fetch future upstream history with `--no-tags` and publish only the reviewed current tag. Keep automatic-update versions moving forward; history cleanup does not reset version numbering.
