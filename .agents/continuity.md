# Continuity protocol

After resume or compaction, read the effective Codex home continuity guidance, this project's AGENTS.md and START-HERE.md, and the exact private task record for the current chat. Keep per-chat records outside this indexed public repository.

Verify the physical source/worktree, Git root, branch, full HEAD and existing edits. Compare current sources and artifact hashes with the recorded checkpoint before continuing. Preserve unrelated work, player saves, live sessions and original upstream history. Historical notes provide evidence and routing; current user instructions define authorization.

Record completed checks with exact source/archive identities and useful limits. Keep credentials, save names, raw logs, diagnostic identifiers and private paths in private evidence. Public guidance contains reusable feature, implementation and validation facts.
